这是一篇针对当前博客环境（Astro + ShokaX 主题）重写的“新建文章示例”。与旧版 Hexo 不同，新博客使用 `src/posts/` 存放文章、`src/theme.config.ts` 管理主题配置、`src/content/` 存放公告等页面内容。

## 一、文章存放在哪里

新主题使用 Astro 的内容集合（Content Collections）来管理文章：

- 文章文件放在 `src/posts/` 目录下，文件名会作为文章访问路径的一部分。
- 每篇文章顶部需要写 YAML Front-Matter，其中 `tags` 与 `categories` 都要求使用数组写法。

## 二、写一篇新文章

1. 在 `src/posts/` 下新建一个 Markdown 文件，例如 `hello.md`。
2. 在文件顶部填写 Front-Matter：

```markdown
---
title: 文章标题
description: 文章简介（可选，会用于列表摘要与 SEO）
date: 2026-09-09 10:00:00
categories: [教程]
tags: [ShokaX, Astro]
sticky: false
---

这里是正文内容。
```

要点：

- `title` 必填，是文章标题。
- `date` 必填，用于排序。
- `tags` 与 `categories` 使用数组写法：`[标签1, 标签2]`。
- `sticky: true` 可以把文章置顶到首页顶部。

## 三、图片管理

新主题把文章图片统一放在 `src/assets/images/` 下，建议按文章名建子文件夹：

```text
src/assets/images/
└── hello/
    └── demo.png
```

在文章里用相对路径引用：

```markdown
![示例图片](../assets/images/hello/demo.png)
```

也可以直接使用网络图片：

```markdown
![网络图片](https://example.com/image.png)
```

## 四、主题配置：src/theme.config.ts

几乎所有主题显示效果都由 `src/theme.config.ts` 控制。下面覆盖了头像、导航栏、用户名、首页副标题与公告相关的常用配置。

### 4.1 头像

头像不是写在配置里，而是替换主题内置文件：

- 找到 `src/assets/avatar.avif`。
- 用自己的头像覆盖它，保持文件名不变。
- 建议使用接近正方形的图片（例如 160×160 或更大）。

### 4.2 导航栏

顶部导航栏由 `nav` 数组控制，每一项包含 `text`、`href` 和可选的 `icon`；带子菜单的项使用 `dropbox`：

```ts
nav: [
  { text: "首页", href: "/", icon: "i-ri-home-line" },
  { text: "关于", href: "/about/", icon: "i-ri-user-3-line" },
  {
    text: "文章",
    href: "/random/",
    icon: "i-ri-quill-pen-fill",
    dropbox: {
      enable: true,
      items: [
        { text: "分类", href: "/categories/", icon: "i-ri-book-shelf-fill" },
        { text: "标签", href: "/tags/", icon: "i-ri-price-tag-3-fill" },
        { text: "归档", href: "/archives/", icon: "i-ri-archive-line" },
      ],
    },
  },
  { text: "动态", href: "/moments/", icon: "i-ri-chat-quote-line" },
]
```

说明：

- 站内链接建议保留末尾的 `/`（主题开启 `trailingSlash: "always"`）。
- 图标使用 UnoCSS + Iconify 的 Remix Icon 类名，例如 `i-ri-home-line`、`i-ri-github-fill`。

### 4.3 用户名与简介

用户名和简介在 `sidebar` 字段中：

```ts
sidebar: {
  author: "Smartre97",
  description: "一名热爱折腾前端与游戏开发的开发者",
  social: {
    github: {
      url: "https://github.com/Smartre97",
      icon: "i-ri-github-fill",
      color: "var(--color-blue)",
    },
  },
}
```

`sidebar.social` 是一个对象，键名可以自定义，值包含 `url`、`icon` 和可选的 `color`。

### 4.4 首页标题与副标题

首页封面下方的大标题、副标题和 Logo 在 `brand` 字段中：

```ts
brand: {
  title: "我的博客",
  subtitle: "记录开发与生活", // 默认值为 "A modern blog theme"
  logo: "✨",
}
```

原来的“A modern blog theme”就是 `brand.subtitle` 的默认值，把它改成你自己的副标题即可。

### 4.5 首页文章数量与分类卡片

首页每页显示多少篇文章、以及顶部突出哪些分类，由 `home` 字段控制：

```ts
home: {
  pageSize: 5,
  selectedCategories: [{ name: "教程" }, { name: "前端" }],
}
```

`selectedCategories` 里的 `name` 必须和文章 `categories` 中的名称完全一致。

### 4.6 站点公告

公告内容存放在 `src/content/announcement.md`，markdown 写法：

```markdown
---
title: 站点公告
---

欢迎来到我的博客 👋

- 这里主要分享开发笔记与踩坑记录。
- 如果发现文章有问题，欢迎到仓库提交 issue。
```

公告会在三栏布局的右侧栏中显示为一张卡片；如果不想要，可以在 `theme.config.ts` 中关闭：

```ts
layout: {
  rightSidebar: {
    announcement: false,
  },
}
```

右侧栏卡片默认顺序由 `layout.rightSidebar.order` 控制。

## 五、完整配置示例

把上面几部分合起来，`src/theme.config.ts` 大致长这样：

```ts
import { defineConfig } from "./toolkit/themeConfig";

export default defineConfig({
  siteName: "我的博客",
  locale: "zh-CN",

  brand: {
    title: "我的博客",
    subtitle: "记录开发与生活",
    logo: "✨",
  },

  sidebar: {
    author: "Smartre97",
    description: "一名热爱折腾前端与游戏开发的开发者",
    social: {
      github: {
        url: "https://github.com/Smartre97",
        icon: "i-ri-github-fill",
      },
    },
  },

  nav: [
    { text: "首页", href: "/", icon: "i-ri-home-line" },
    { text: "关于", href: "/about/", icon: "i-ri-user-3-line" },
    {
      text: "文章",
      href: "/random/",
      icon: "i-ri-quill-pen-fill",
      dropbox: {
        enable: true,
        items: [
          { text: "分类", href: "/categories/", icon: "i-ri-book-shelf-fill" },
          { text: "标签", href: "/tags/", icon: "i-ri-price-tag-3-fill" },
          { text: "归档", href: "/archives/", icon: "i-ri-archive-line" },
        ],
      },
    },
    { text: "动态", href: "/moments/", icon: "i-ri-chat-quote-line" },
  ],

  home: {
    pageSize: 5,
    selectedCategories: [{ name: "教程" }],
  },

  layout: {
    rightSidebar: {
      announcement: true,
    },
  },
});
```

## 六、常用 Markdown 写法速查

- 插入链接：`[访问 Google](https://www.google.com)`
- 行内代码：用一对反引号包住内容，例如 `console.log("Hello World")`
- 删除线：`~~删除线~~`
- 高亮：`==荧光高亮==`
- 代码块：用三个反引号包裹，并写上语言名称（C++ 写 `cpp`）：

```cpp
#include <iostream>
int main() {
  std::cout << "Hello" << std::endl;
}
```
