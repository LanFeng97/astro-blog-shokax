title: 三目运算符的增强
date: 2026-08-14 16:00:13
categories: [c++]
tags: [c++]

c++相对c语言增强了三目运算符：当两个分支都是同类型的左值时，整个表达式的结果是左值（而非纯右值），可以放在等号左侧被赋值。这是 C++98 就有的特性，不是 C++11 新增。

```cpp
    int a=10;
    int b=20;
    int c=0;
    c = (a<b)?a:b;
    cout << c << endl;
    ((a<b)?a:b)=50;//三目运算符可以当左值，这里给a赋值50
    cout <<a<<endl;//输出50
```
